# 사용량 보고 (Cowork 취합용)

Claude가 매일 자기 사용량 조회 결과(get_usage)를 원문 그대로 남긴다.
나중에 모아서 집계할 수 있도록 아래 형식을 지킨다.

## 파일
- 경로: `usage/<ai이름>/YYYY-MM-DD.md` (Claude는 `usage/claude/`)
- 날짜는 KST 기준. 하루에 두 번 이상 남기면 `YYYY-MM-DD-HHmm.md`
- 한 파일에 JSON 블록은 하나만 둔다.

## 본문
- 머리말: 보고자, 조회 수단, 조회 시각(KST)
- 로컬 절대경로는 적지 않는다. 파일 이름만 적는다. (공개 저장소)
- `## 오늘 작업`: 그 파일 날짜에 한 일만 적는다. 다른 날 일은 그 날짜 파일에.

## 숫자
- 조회 결과 JSON은 원문 그대로 붙인다. 요약·추정·계산하지 않는다.
- 창(window)은 조회된 것만 적는다. 없는 창을 0으로 채우지 않는다.
- `extraUsage.spent`는 비용으로 쓰지 않는다. 뜻이 확인되지 않았고 한도가 0이라 실제 지출이 아니다. (2026-11-18 확인)

## 정정
- 지난 보고를 정정하면 오늘 파일에 적고, **원래 파일 맨 위에도 한 줄 남긴다.**
  예: `> 정정 있음: 2026-11-18.md 참고`
- 원래 숫자는 지우지 않는다.
